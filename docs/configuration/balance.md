## Goldとショップ

| 項目 | 現在値 |
|---|---:|
| 占領1拠点の進行Gold | 25 |
| 戦闘勝利1回の進行Gold | 5 |
| 敗北時の換算率 | 25% |
| 敗北時の救済Gold上限 | 30 |
| 敗北報酬に必要な最低経過時間 | 30秒 |
| 敗北報酬に必要な最低占領数 | 1拠点 |
| クリアボーナス | 150 |
| 次レベル価格倍率 | 1.45 |
| 価格の切り上げ単位 | 10 Gold |
| 価格上限 | 999,999 Gold |

作戦中の進行Goldは、その作戦で初めて占領した拠点の数と戦闘勝利数から次の式で求めます。同じ拠点の奪還は、占領数として重複計上しません。

```text
進行Gold = 占領数 × 25 + 戦闘勝利数 × 5
敗北報酬 = min(30, floor(進行Gold × 0.25))
クリア報酬 = 進行Gold + 150
```

敗北時は、最低30秒が経過し、1拠点以上を占領している場合だけ救済Goldを付与します。作戦中の進行Goldと報酬は、作戦をまたいで持ち越しません。

```text
価格 = ceil(基本価格 × 価格倍率 ^ 現在レベル ÷ 切り上げ単位) × 切り上げ単位
```

| 強化 | 基本価格 | 1レベルの効果 |
|---|---:|---|
| 兵站網 | 100 Gold | プレイヤー領土の生産力+1 |
| 強化装甲 | 100 Gold | プレイヤー部隊の最大戦力+3 |
| 予備部隊 | 150 Gold | 次回作戦の初期プレイヤー部隊+1 |

## 調整時の確認観点

- 生産力を上げた場合、回復だけでなく集団戦闘の与ダメージも増える。
- 最大戦力と回復量の両方を上げると、占領不能な膠着が起きやすい。
- 占領時間を延ばすと迎撃猶予は増えるが、無人拠点の制圧テンポが落ちる。
- AI上限と待機時間を同時に強化すると、有限増援でも序盤難度が急上昇する。
- プレイヤー初期部隊数はシナリオ、1体ごとの強さはバランスで変更する。
