# 勢力設定

- 正となるコード: `src/config/factions.js`
- 役割の割り当て: [シナリオ設定](./scenario.md)

勢力設定は見た目と表示文言を定義します。どの勢力をプレイヤーや能動AIにするかは、勢力そのものへ固定せずシナリオ側で指定します。

| ID | 表示名 | 部隊画像 | フォールバック様式 |
|---|---|---|---|
| `blue` | White Union | `player-red-circle.png` | `visor` |
| `red` | 赤勢力 | `enemy-china.png` | `cap` |
| `neutral` | 中立勢力 | `enemy-korea.png` | `plain` |
| `pink` | 桃勢力 | `enemy-north-korea.png` | `plain` |

各勢力は次を持ちます。

- 内部IDと表示名
- 部隊画像と画像読込失敗時の様式
- 領土、境界、拠点名、部隊、旗、占領表示の配色
- 拠点情報パネルの表示クラス、平常時の説明、脅威表示

## 勢力追加チェック

1. `factions.js` に重複しないIDと必要な表示設定を追加する。
2. 画像を `assets/units` に追加し、`unitSprite` から参照する。
3. `balance.js` に基本最大戦力と移動速度を追加する。
4. 使用するシナリオの初期所有または初期部隊へ割り当てる。
5. Service Workerのアプリシェルへ新しい画像を追加する。

国旗をモチーフにした画像はローカルアセットとして同梱し、ゲーム内で参照元や外部URLに依存しない状態を維持します。
