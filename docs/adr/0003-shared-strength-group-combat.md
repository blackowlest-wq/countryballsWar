# 集団戦闘では合算戦力から損耗を共有する

複数部隊が同時に交戦したとき、先頭の一体へ順番にダメージを集中させる方式は、参加部隊が簡単に消滅して集団で戦う利点が伝わりにくい。そこで勢力ごとに戦力を合算し、受けたダメージを合算戦力から差し引いた後、残存戦力を各部隊へ再配分する共有損耗方式を採用する。

## Consequences

- 戦闘計算と勝敗判定は個別部隊ではなく戦力グループを単位にする。
- 単一部隊への不自然な集中損耗を避けられる一方、戦闘UIにはグループ全体で消耗していることが分かる表現が必要になる。
- ダメージ係数や再配分の丸め方はバランス値として設計資料で管理する。
