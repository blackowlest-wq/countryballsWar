# 193か国の世界制覇キャンペーンとG7開始国を採用する

COUNTRYFRONTSは、国連加盟国193か国を対象に、13地域とロシア特別戦線へ分けた世界制覇キャンペーンとして進行する。小国は14の地域連合戦、大国は9つの大国決戦、終盤は世界連合戦と最終勢力戦の計25戦枠で扱い、オブザーバー国・自治領は本編の制圧対象から除外する。新規キャンペーンではG7から一か国を開始国として選び、その国を初期制圧済み・国旗図鑑登録済みとする。

## Consequences

- 敗北しても、キャンペーンで制圧済みの国・地域、国旗図鑑、永続Gold、強化は保持し、未制圧の現在戦線だけを再挑戦する。
- 開始国が地域連合戦の参加国である場合は、その国だけを制圧済みとして扱い、残りの参加国を戦線の対象にする。開始国が大国決戦の対象である場合は、その決戦を制圧済みとして扱う。
- 24戦目の世界連合戦と25戦目の最終勢力戦は、新しい国を追加せず、既に登場した国・勢力を再編成して扱う。
- 開始国の選択によって初期の難易度と進行順が変わるため、開始時の部隊数・報酬・強化効果はバランス調整の対象になる。
