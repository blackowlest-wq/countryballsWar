# 道路上のリアルタイム侵攻と守備隊を持たない防衛を採用する

ゲーム進行はターン制ではなくリアルタイムとし、部隊は自由移動ではなく道路グラフ上だけを移動する。固定守備隊による防衛は、生産力回復と組み合わさると占領条件が分かりにくく膠着しやすいため廃止し、防衛は「侵攻予告あり！」、5秒の占領タイマー、道路上または拠点上での迎撃によって表現する。

## Consequences

- 派遣可能性は距離ではなく道路経路の有無で決まる。
- 複数道路を通る目的地への派遣を許可し、経路上で接敵した場合はその場で止まる。
- 道路線、攻撃対象、侵攻予告、占領残り時間を常に読み取れるUIが必要になる。
- 拠点へ防衛値や守備専用ユニットを後付けしない。
