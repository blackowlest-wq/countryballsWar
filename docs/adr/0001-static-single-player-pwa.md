# シングルプレイの静的PWAとして提供する

COUNTRYFRONTSはオンライン対戦、ランキング、アカウントを持たない個人向けゲームとし、HTML・CSS・JavaScriptだけの静的PWAとしてCloudflare Pagesから提供する。バックエンドを持つ構成も検討対象になり得るが、現在必要なゲーム進行とGold・強化の保存はブラウザ内で完結でき、運用負荷を増やさずインストールとオフライン起動を実現できるため、この構成を採用する。

## Consequences

- サーバー費用、認証、同期、ランキング不正対策を必要としない。
- Goldと強化は端末・ブラウザ単位であり、端末間同期や復旧はできない。
- 将来オンライン機能を追加する場合は、保存モデルと信頼境界を新たに設計する必要がある。
