# 固定開始とプレイヤー外観の分離を採用する

ADR 0004で定めたG7からの開始国選択を取りやめ、新しいキャンペーンは固定された初期配置から開始する。White Unionの標準キャラクターは白塗りとし、オプションで見た目を変更できるが、外観はゲーム能力や進行に影響しない。193か国、13地域とロシア特別戦線、25戦枠の構成は維持する。

## Consequences

- G7を含む193か国すべてが、開始時には未制圧の制圧対象になる。
- 開始国の選択による初期難易度や進行順の差がなくなり、強化と戦線のバランスを固定初期配置を基準に調整できる。
- プレイヤー外観は制圧状況、国旗図鑑、Gold、強化、報酬から分離し、見た目だけを変更する。
- G7選択画面は用意せず、外観変更はオプション画面の設定として扱う。
