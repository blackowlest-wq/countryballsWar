# COUNTRYFRONTS ゲーム設計仕様

- 状態: 合意済みベースライン
- 更新日: 2026-08-17
- 基準実装: `main` ブランチ
- 関連資料: [ドメイン用語集](../CONTEXT.md)、[可変ゲーム設定](./configuration/)、[ADR一覧](./adr/)

この資料は、これまでに合意した安定したゲームルールをまとめたものです。マップ、初期配置、生産力、戦闘係数など変更頻度の高い具体値は [可変ゲーム設定](./configuration/) へ分離します。

## 1. ゲームの目的と範囲

COUNTRYFRONTSは、国旗をモチーフにした部隊を操作して国連加盟国193か国の制圧を目指す、シングルプレイ専用のリアルタイム戦略ゲームです。

- プレイヤーは白い勢力「White Union」を操作する。
- オンライン対戦、アカウント、ランキングは実装しない。
- 13地域とロシア特別マップからなる世界制覇キャンペーンを進行する。
- プレイヤーの標準外観は白塗りのキャラクターとし、国旗図鑑の「着替え」で実キャラクター画像を装着できる。「外す」で標準外観へ戻す。
- 外観の変更は能力、所属勢力、進行状態、報酬に影響しない。
- 制圧済みの国・地域、国旗図鑑、永続Gold、強化は敗北後も保持する。
- 国旗図鑑では制圧済みの国旗と国の説明を閲覧できる。
- BGMは現段階では使用しない。
- ブラウザだけで動作する静的PWAとして提供する。
- Cloudflare Pagesを公開先とし、ビルド工程とバックエンドを必要としない。

## 2. コアループ

1. 各部隊が現在地の生産力に応じて戦力を回復する。
2. プレイヤーが白い部隊をドラッグまたはスワイプし、目的拠点へ派遣する。
3. 部隊は道路で構成された経路上をリアルタイムに移動する。
4. 敵部隊と接触した場合はその場で交戦し、移動を停止する。
5. 敵対拠点へ到着し、交戦していない状態を維持すると占領が完了する。
6. 現在のマップに割り当てられた未制圧国をすべて制圧するとマップクリアとなる。
7. White Unionの全部隊を失うと敗北となる。

### 2.1 世界制覇キャンペーン

- 本編の制圧対象は国連加盟国193か国とし、オブザーバー国・自治領は対象外とする。
- 地域の所属はゲーム上の固定分類とし、国を重複して数えない。

| 地域・特別マップ | 国数 |
|---|---:|
| 北米 | 3 |
| 中米 | 7 |
| カリブ | 13 |
| 南米 | 12 |
| 欧州 | 42 |
| 北ユーラシア（ロシア） | 1 |
| 北アフリカ | 6 |
| サブサハラ・アフリカ | 48 |
| 中東・コーカサス | 18 |
| 中央アジア | 5 |
| 南アジア | 8 |
| 東アジア | 5 |
| 東南アジア | 11 |
| オセアニア | 14 |
| 合計 | **193** |

- 進行は地域連合戦14戦、大国決戦9戦、世界連合・最終勢力戦2戦の合計25戦枠を基本とする。
- 1〜23戦目のマップに193か国を一度ずつ割り当て、開始時点ではすべて未制圧とする。24・25戦目は既出の国・勢力を再編成して登場させる。
- 地域連合戦では、参加国をそれぞれ自国の国旗を持つ代表として順番に登場させる。各国の全拠点を制圧した時点で、その国を制圧済みとし、国旗を国旗図鑑へ登録する。
- 大国決戦では、一つの主役国を前半・後半の2局面で扱う。両局面の中心には主役国の国旗を持つ代表を配置し、後半の敵を強くする。主役国の全拠点を制圧した時点で、その国の国旗を国旗図鑑へ登録する。
- 各マップの実プレイ時間は5〜10分を目標とする。小規模地域戦は5〜6分、大規模地域戦は8〜10分、大国決戦は前半・後半を合わせて6〜8分、世界連合・最終勢力戦は8〜10分を目安とする。
- 新しいキャンペーンは固定された初期配置から開始し、開始時点で制圧済みの国は存在しない。G7を含む193か国すべてを制圧対象とする。
- 敗北時は現在の未制圧マップを再挑戦し、制圧済みの国・地域は失わない。

## 3. 操作と時間

### 3.1 操作

- 拠点のクリックまたはタップ: 拠点情報を表示する。
- 白い部隊から拠点へのドラッグまたはスワイプ: 派遣命令を出す。
- 必殺技ボタン: 作戦中に設定した必殺技を使用する。使用回数が残っている場合だけ使用できる。
- マップ操作: 拡大、縮小、初期位置への復帰を提供する。
- 部隊派遣に専用資源は消費しない。
- 派遣回数に人為的な上限は設けず、存在する部隊数と戦力を自然な制約とする。

### 3.2 時間

- ゲームはターン制ではなくリアルタイムで進行する。
- 起動時はタイトル画面を表示し、「スタート」が押されるまでゲーム時間、AI、戦闘を進めない。
- 一時停止、1倍速、2倍速、4倍速を提供する。
- ショップを開いている間は自動的に一時停止し、閉じると元の停止状態へ戻る。
- ゲーム内の日数を表示する。1日の長さはバランス設定で変更でき、ターンを意味しない。

### 3.3 必殺技の初回設定

- 初めてゲームを開始するとき、またはデータをリセットした直後に、必殺技を設定する。
- 必殺技は「敵弱体化」「味方強化」「無敵」から一つを選び、初期名を任意の名前へ変更できる。
- 必殺技の種類と名前はブラウザに保存する。作戦の途中状態と作戦中の残り使用回数は保存しない。
- 新しい作戦を開始するたびに、必殺技の使用回数を選択中の難易度に応じて初期化する。やさしいは3回、ふつうは1回、むずかしいは0回とする。

### 3.4 難易度

- タイトル画面の「スタート」から、マップ選択の前に難易度を選択する。
- 難易度はキャンペーン単位で固定し、選択後は作戦中・同じキャンペーンの進行中に変更できない。データリセット後は再選択できる。
- 敵部隊の開始時最大戦力は、マッププロファイルと難易度の倍率を掛けて `round` する。現在のマップ上の戦力値は参照しない。
- 難易度ごとの条件は次のとおりとする。

| 難易度 | 敵戦力倍率 | 必殺技 | 回復力 / 戦力 / 開始人数 / 速度アップの強化上限 |
|---|---:|---:|---:|
| やさしい | ×0.8 | 3回 | Lv.8 / Lv.8 / Lv.5 / Lv.8 |
| ふつう | ×1.0 | 1回 | Lv.6 / Lv.6 / Lv.4 / Lv.6 |
| むずかしい | ×1.2 | 0回 | Lv.4 / Lv.4 / Lv.2 / Lv.4 |

- 強化上限は購入にだけ適用し、難易度変更やデータ移行で既存レベルを下げない。

## 4. マップと道路

### 4.1 マップ構成ルール

- 一つのマップの拠点数は10〜15とする。
- プレイヤーは一つの拠点だけを初期所有し、そこから開始する。
- 敵部隊は国旗が示す自国の拠点に配置する。部隊の`characterId`と拠点の`countryId`は一致させる。
- 中立勢力は使用せず、プレイヤー以外のすべての勢力を敵として扱う。
- マップ上の国を制圧済みとする条件は、その国に属する全拠点をプレイヤーが所有することである。
- 大国マップは同じマップ内で前半・後半などの局面に分けられる。局面切替時はプレイヤーの部隊と占領状態を引き継ぎ、敵部隊だけを次局面の初期配置へ置き直す。

### 4.2 移動ルール

- 部隊は道路上だけを移動し、マップ上を自由移動しない。
- 派遣先は、派遣元から道路グラフ上で到達可能な任意の拠点とする。
- 複数区間を通る場合は、道路数が最少となる経路を選択する。
- 部隊は経路上の拠点中心を順番に通過する。
- 占領対象になるのはプレイヤーが選択した最終目的拠点だけであり、中継拠点は通過する。
- 道路上で敵と接触した場合は、その地点で移動を停止して交戦する。勝者は経路移動を再開する。
- 到着後は最終目的拠点の中心に駐留し、新たな派遣命令を受けるまで移動しない。

### 4.3 道路接続

道路は拠点間の双方向グラフとし、辺を一度だけ定義して実行時に隣接表へ変換する。現在の拠点形状と接続は [マップ設定](./configuration/map.md) を参照する。

## 5. 勢力、キャラクター、初期状態

### 5.1 キャラクター対応

プレイヤーのWhite Unionは白塗りで黒い目を持つ。プレイヤーと敵の全キャラクター画像はローカルアセットとして同梱する。

勢力ごとの画像と配色は [勢力設定](./configuration/factions.md)、プレイヤー・AIの役割と初期部隊数は [シナリオ設定](./configuration/scenario.md) を参照する。

### 5.2 拠点、初期所属、生産力

拠点形状と道路、初期所属、生産力を別々に管理する。現在値は [マップ設定](./configuration/map.md)、[シナリオ設定](./configuration/scenario.md)、[バランス設定](./configuration/balance.md) を参照する。

## 6. 戦力と生産力

- 戦力は部隊の耐久力と攻撃力を兼ねる整数値とする。
- 戦力が0以下になった部隊は消滅する。
- すべての勢力の部隊は、設定された回復判定ごとに現在地の生産力と同じ量だけ戦力を回復する。
- 回復は最大戦力を超えない。
- 回復は停止中、移動中、交戦中のいずれでも行う。
- 生産力は部隊派遣のコストには使用しない。
- 勢力ごとの基本最大戦力はバランス設定で指定する。

## 7. 侵攻、防衛、占領

### 7.1 守備方式

独立した守備隊や固定防衛値は使用しない。防衛は次の三要素で表現する。

1. **侵攻予告**: 敵の出撃前に「侵攻予告あり！」と対象拠点、残り時間を表示する。
2. **占領タイマー**: 敵対拠点へ到着しても即時占領せず、一定時間の維持を必要とする。
3. **道路上の迎撃**: 侵攻部隊と接敵すると移動と占領進行を停止する。

### 7.2 占領ルール

- 敵対拠点へ到着すると、設定された占領時間の進行を開始する。
- 占領側の部隊が交戦中の間、タイマーは停止する。
- 占領担当部隊が消滅または離脱しても、同勢力の別部隊が拠点にいれば担当を引き継ぐ。
- 占領側の部隊が拠点からいなくなった場合、占領進行は破棄する。
- 占領時間を維持すると拠点所属を占領側へ変更する。

## 8. 集団戦闘

### 8.1 グループ化

- 接触距離はマップ正規化座標のバランス値で指定する。
- 接触関係で連結している全部隊を一つの戦闘として扱う。
- 同一戦闘内で勢力ごとに戦力グループを作る。
- 交戦中の部隊は移動できず、占領進行も停止する。

### 8.2 ダメージ

戦闘判定は設定された間隔で行う。勢力グループが1回に与えるダメージは次式とする。

```text
基礎ダメージ = ceil(合算戦力 × 戦力係数 + 合算生産力 × 生産力係数)
実ダメージ   = clamp(基礎ダメージ, 最低ダメージ, 合算戦力)
```

- 敵勢力が複数ある場合、与ダメージを敵勢力数で均等に分割する。
- 各勢力が受けるダメージを合計して整数に丸める。
- ダメージは特定の先頭部隊ではなく、戦力グループの合算戦力から差し引く。
- 判定間隔と各係数の現在値は [バランス設定](./configuration/balance.md) を参照する。

### 8.3 共有損耗の再配分

- 残存合算戦力を各部隊の最大戦力比率に応じて再配分する。
- 合算戦力が部隊数以上なら、可能な限り各部隊を最低1戦力で残す。
- 合算戦力が部隊数未満なら、現在戦力が高い部隊から1戦力ずつ残し、残せない部隊は消滅する。
- この方式により、複数部隊で戦う際に一体だけが先に集中消耗することを防ぐ。

### 8.4 必殺技

- 必殺技は作戦中に使用する消耗制の戦術であり、使用回数は作戦の再開時に難易度ごとの初期値へ戻る。
- 「敵弱体化」は戦場に存在する敵部隊の現在戦力を20%減らす。
- 「味方強化」は戦場に存在するWhite Union部隊の現在戦力を20%増やす。最大戦力を超えない。
- 「無敵」はWhite Union部隊を3秒間、戦闘ダメージと敗北判定から保護する。
- 効果の割合と無敵時間は [バランス設定](./configuration/balance.md) で管理する。

## 9. 敵AIと有限増援

- シナリオで指定した能動侵攻AIは作戦開始時から侵攻候補を持つ。
- それ以外のプレイヤー以外の勢力も、自勢力拠点とプレイヤー拠点が道路で直接接続された時点から侵攻候補を持つ。
- 各AI勢力は自勢力拠点から、道路で直接接続されたプレイヤー拠点を選んで侵攻する。
- 出撃前に設定時間の侵攻予告を行う。
- AI勢力ごとに同時存在部隊数と、一作戦中に生成できる増援数に上限を設ける。
- 既に同じ目的拠点へ向かう同一勢力のAI部隊がいる場合、同じ侵攻を重複生成しない。
- この有限化により、敵戦力が無限に出現する状態を防ぐ。
- 現在のAI勢力と数値は [シナリオ設定](./configuration/scenario.md) と [バランス設定](./configuration/balance.md) を参照する。

## 10. 勝敗と再開

### 10.1 クリア

- 現在のマップに割り当てられた未制圧国をすべて制圧した時点で、そのマップをクリアとする。
- 国旗図鑑への登録は、各国に属する全拠点の占領完了時点で確定する。マップクリア判定とは別に扱い、作戦中の通知でプレイヤーへ知らせる。
- 25戦目の最終勢力戦をクリアした時点で、世界制覇キャンペーンをクリアとする。
- マップクリア時はゲームを一時停止し、次のマップへ進む操作を表示する。

### 10.2 敗北

- White Unionの部隊が1体も存在しなくなった時点で、現在の作戦を敗北とする。制圧済みの国・地域が残っていても敗北しない。
- ゲームを一時停止し、敗北ダイアログを表示する。
- 作戦中に初めて占領した拠点の数と戦闘勝利数から進行Goldを計算し、その35%を基準に、最低20 Gold・上限60 Goldの敗北救済Goldを一度だけ付与する。同じ拠点の奪還は重複計上しない。
- 30秒未満、または1拠点も占領していない敗北には救済Goldを付与しない。
- 作戦中に制圧完了した国・地域と国旗図鑑の登録は敗北後も保持する。
- 「再挑戦」で未制圧国が残る現在のマップを初期配置から再開できる。

### 10.3 クリア報酬

- マップを制圧した時点で、作戦中の進行Gold全額とマップクリア報酬を付与する。
- 世界制覇キャンペーンをクリアした時点で、最終クリアボーナスを一度だけ付与する。
- クリア報酬は敗北救済Goldより大きくなるように設定し、敗北を繰り返すより作戦を継続してクリアする方が有利になるようにする。

### 10.4 タイトル画面と再開方法

- 起動時にタイトル画面を表示し、「スタート」と「データをリセット」を提供する。
- タイトル画面に「集めた国旗」を表示し、国旗図鑑を開いて獲得済み・未獲得の国旗と獲得数を確認できる。
- 新規キャンペーン、または難易度未選択のキャンペーンで「スタート」を選ぶと、マップ選択の前に難易度を選択する。
- 選択した難易度はキャンペーンに保存し、マップ選択画面にも表示する。
- 新しいキャンペーンの「スタート」では固定された初期配置から開始する。
- 進行中のキャンペーンの「スタート」では、保存済みの制圧状況、国旗図鑑、Gold、強化レベルを保持して未制圧マップを開始する。
- クリア・敗北後の再戦も、制圧状況、国旗図鑑、Gold、強化レベルを保持して現在のマップを初期化する。
- 「データをリセット」は確認後、キャンペーンの制圧状況、Gold、全強化レベル、選択済み難易度、マップのクリア状況を初期値へ戻す。ただし、国旗図鑑と取得済み地図の解放状況は保持する。
- 「データをリセット」は、必殺技の設定も未設定へ戻す。次回の「スタート」で再設定する。
- データをリセットしてもタイトル画面には留まり、プレイヤーが「スタート」を選ぶまで戦闘を開始しない。

## 11. Goldとショップ

- Goldは現在ショップ専用通貨とし、通常HUDには表示せず、ショップ内だけに表示する。
- Goldは、作戦中に初めて占領した拠点・戦闘成果に応じた進行Gold、マップクリアボーナス、世界制覇クリアボーナスから獲得する。
- 敗北時は進行Goldの一部だけが救済Goldとして永続Goldへ変換され、作戦を最初からやり直しても進行Gold自体は持ち越さない。
- Goldと購入済み強化レベルはブラウザに保存し、作戦をまたいで保持する。
- 保存済みGoldと強化レベルは、タイトル画面の「データをリセット」で明示的に初期化できる。
- 強化は選択中の難易度ごとの上限まで購入できる。保存済みレベルが上限を超えている場合は下げず、追加購入だけを停止する。
- 次レベル価格は設定された倍率、切り上げ単位、上限で算出する。

```text
価格 = ceil(基本価格 × 価格倍率 ^ 現在レベル ÷ 切り上げ単位) × 切り上げ単位
```

| 強化 | 効果 | 適用時期 |
|---|---|---|
| 回復力 | 自軍領土の生産力を増やす | 即時、以後の作戦にも保持 |
| 戦力 | プレイヤー部隊の最大戦力を増やす | 既存部隊と以後の作戦に適用 |
| 開始人数 | 開始時のプレイヤー部隊を増やす | 次回の新規作戦から適用 |
| 速度アップ | プレイヤー部隊の移動速度を増やす | 即時、以後の作戦にも保持 |

価格と1レベルあたりの効果は [バランス設定](./configuration/balance.md) を参照する。

派遣可能数の拡張は強化項目に含めない。

## 12. UIとフィードバック

- マップをゲームの主領域とし、情報パネルや操作ボタンで重要拠点を覆わない。
- ショップと設定は上部ヘッダーへ配置する。
- 一時停止と速度変更は上部ヘッダー、経過時間と必殺技操作はマップ外の下部へ配置する。
- 攻撃可能な拠点には `ATTACK` または `TARGET` を表示する。
- 交戦時は戦闘エフェクトと `BATTLE` 表示で明示する。
- 侵攻予告は対象拠点とカウントダウンを表示する。
- 作戦中はフッターに必殺技名、残り使用回数、使用ボタンを表示する。
- 拠点情報には所属、占領進行、生産力、戦況を表示する。
- 戦力値は背景に埋もれない黒系文字で表示する。
- プレイヤー部隊は白塗りで黒い目を表示して自軍を識別しやすくする。

## 13. 保存、PWA、公開

- アプリ本体はHTML、CSS、JavaScript、画像のみで構成する。
- Service Workerでアプリ本体と画像をキャッシュし、インストール後のオフライン起動を可能にする。
- PWAはスタンドアロン、縦向き優先で起動する。
- Goldと強化は `localStorage` に保存する。
- 必殺技の種類・名前は `localStorage` に保存する。
- タイトル画面の「データをリセット」は、確認後にGoldと全強化の保存値を削除し、実行中の値にも即時反映する。
- タイトル画面の「データをリセット」は、必殺技の設定も削除する。
- 現在の作戦の途中状態、経過時間、作戦中の残り使用回数は保存しない。再読み込み時は、保存済みの設定とキャンペーン状態から現在のマップを初期配置で始める。
- Cloudflare Pages設定はFramework presetなし、Build command空欄、Build output directory `/` とする。

## 14. 受入シナリオ

### 複数道路を通る派遣

- Given: 白い部隊と目的拠点の間が複数の道路で接続されている
- When: 部隊を目的拠点へドラッグする
- Then: 派遣が受理され、部隊は中継拠点を順番に通過する

### 道路外への派遣拒否

- Given: 派遣元と目的地の間に道路経路がない
- When: 部隊を目的地へドラッグする
- Then: 派遣は開始されず、道路接続が必要なことを通知する

### 道路上の迎撃

- Given: 異なる勢力の部隊が同じ道路上を接近している
- When: 接触距離内へ入る
- Then: 両者の移動が止まり、戦闘表示と共有戦力による交戦が始まる

### 到着後の駐留

- Given: 部隊が最終目的拠点へ移動している
- When: 経路の終点へ到着する
- Then: 部隊は拠点中心に停止し、次の派遣命令を受けるまで駐留する

### 無人拠点の占領

- Given: 敵対拠点に防衛部隊がいない
- When: 侵攻部隊が到着する
- Then: 即時には所属が変わらず、設定された占領時間後に占領が完了する

### 敗北救済

- Given: White Unionの部隊が残り1体である
- When: その部隊の戦力が0になる
- Then: 敗北画面を表示し、条件を満たしていれば作戦進行の35%を基準に最低20 Gold・上限60 Goldの救済Goldを付与し、制圧済み国を保持して現在のマップを再挑戦できる
- And: 30秒未満または占領数0の場合、救済Goldは0とする

### クリア報酬

- Given: White Unionが現在のマップに割り当てられた未制圧国をすべて制圧している
- When: クリア判定が発生する
- Then: 作戦進行Gold全額とマップクリア報酬を付与し、次のマップへ進む画面を表示する

### タイトルから開始

- Given: アプリを起動してタイトル画面が表示されている
- When: プレイヤーが操作せず待機する
- Then: ゲーム時間、AI、戦闘は進行しない
- When: 「スタート」を選択する
- Then: 難易度未選択なら難易度選択画面を表示し、選択済みならマップ選択画面を表示する
- When: 難易度とマップを選択する
- Then: 選択した難易度の条件を適用し、固定された初期配置からリアルタイム進行を開始する

### 難易度の条件

- Given: 朝鮮半島マップの敵プロファイル倍率が0.85である
- When: やさしい、ふつう、むずかしいのいずれかで作戦を開始する
- Then: 基本戦力12の敵部隊は、それぞれ8、10、12へ `round` される
- And: 必殺技の初期使用回数は、それぞれ3回、1回、0回となる
- And: 強化購入は、選択難易度の上限を超えて実行できない

### 国旗獲得

- Given: 韓国の拠点が残り1つで、その他の韓国拠点はWhite Unionが制圧している
- When: 最後の拠点の占領が完了する
- Then: 「韓国の国旗を獲得しました！」を通知し、国旗図鑑へ韓国の国旗を登録する
- And: 同じ国旗は再戦や奪還後にもう一度通知せず、登録状態を保持する

### 中国マップの解放

- Given: 朝鮮半島マップと日本マップをクリアしている
- When: マップ選択画面を表示する
- Then: 中国マップを選択でき、海南島だけをWhite Unionが所有する固定初期配置から開始できる

### 中国マップの局面移行

- Given: 中国マップ前半の南部・中央部6拠点をWhite Unionが制圧している
- When: 前半の目標達成判定が発生する
- Then: プレイヤー部隊、戦力、占領状態、選択中のゲーム速度、カメラ位置を維持して後半へ移行する
- And: 前半の敵部隊を除去し、中国北部の5拠点へ後半の敵部隊を再配置する

### 中国の国旗獲得

- Given: 中国マップの14拠点のうち13拠点をWhite Unionが制圧している
- When: 最後の中国拠点の占領が完了する
- Then: 中国の国旗を国旗図鑑へ登録し、中国マップをクリア済みにする

### 永続データのリセット

- Given: キャンペーン進行、国旗図鑑、Goldまたは強化レベルがブラウザに保存されている
- When: タイトル画面で「データをリセット」を選び、確認する
- Then: キャンペーン進行、Goldは初期値、全強化はLv.0となり、保存値と表示へ即時反映される
- And: 国旗図鑑と取得済み地図の解放状況は保持され、マップのクリア表示は初期化される
- And: タイトル画面は閉じず、「スタート」を選ぶまでゲームは進行しない

### クリア

- Given: White Union以外の拠点が残り1つである
- When: 最後の拠点の占領が完了する
- Then: 進捗を100%にし、「クリア！」画面を表示する

### 強化の複数購入

- Given: 次レベル価格以上のGoldを所持している
- When: 同じ強化を複数回購入する
- Then: レベルごとに効果が累積し、次回価格が上昇する

### 必殺技の初回設定

- Given: 初回起動、またはデータリセット直後で必殺技が未設定である
- When: プレイヤーが必殺技の種類と名前を選び、開始する
- Then: 選択した設定が保存され、作戦中に設定した名前と難易度に応じた残り使用回数が表示される
- And: 次の作戦開始時も同じ設定が使われ、作戦中には変更できない

### 必殺技の使用回数

- Given: 作戦を開始している
- When: 必殺技を使用する
- Then: 選択した効果が適用され、残り使用回数が1減る
- And: 同じ作戦中に選択難易度の初期使用回数まで使用できる
- When: 敗北またはクリア後に作戦を再開する
- Then: 使用回数が選択難易度の初期値へ戻る

### 必殺技の効果

- Given: 必殺技の使用回数が残っている
- When: 敵弱体化を使用する
- Then: 戦場の敵部隊の現在戦力が設定割合だけ減る
- When: 味方強化を使用する
- Then: White Union部隊の現在戦力が設定割合だけ増え、最大戦力を超えない
- When: 無敵を使用する
- Then: 設定時間の間、White Union部隊は戦闘ダメージと敗北判定を受けない

## 16. 実装差異と未確定事項

以下は確定仕様からの実装差異、または今後の判断が必要な項目です。

- **中立・桃勢力のAI**: 現在は初期配置のみで、能動侵攻は赤勢力だけ。将来も静的勢力とするか、個別AIを持たせるかは未確定。
- **Gold獲得経路**: 占領・戦闘成果、敗北救済、クリアボーナスを実装済み。具体値はバランス設定で調整する。
- **キャンペーン実装**: 193か国、13地域とロシア特別マップ、25戦の進行構造は確定した。各マップ、国旗アセット、国別説明、保存形式は実装時に定義する。
- **途中セーブ**: 作戦の途中状態は保存せず、制圧済み国・国旗図鑑・Gold・強化などのキャンペーン状態だけを保存する。
- **数値調整**: 生産力、ダメージ係数、占領時間、AI上限は現行基準値であり、プレイテスト結果に応じて調整可能とする。

## 17. 変更管理

- 用語の意味が変わる場合は `CONTEXT.md` を更新する。
- 安定したゲームルールが変わる場合はこの資料を更新する。
- 世界制覇キャンペーンの分類を変更する場合は [ADR 0004](./adr/0004-world-conquest-campaign-and-g7-start.md) を更新または後続ADRで置き換え、開始方式・プレイヤー外観のルールを変更する場合は [ADR 0005](./adr/0005-fixed-start-and-cosmetic-player-appearance.md) を更新または後続ADRで置き換える。
- マップ、勢力、初期状態、バランス値が変わる場合は [可変ゲーム設定](./configuration/) と対応する `src/config` を更新する。
- 静的PWA、リアルタイム道路侵攻、守備方式、集団戦闘方式を覆す場合は、既存ADRを廃止または後続ADRで置き換える。
- 単純なバランス調整やマップ追加はADRを作らない。
