# COUNTRYFRONTS

国旗をモチーフにしたオリジナルの部隊で領土を広げる、リアルタイム戦略ゲームのブラウザ試作です。

## 現在の試作機能

- Canvasによるマップ表示
- 自軍・敵対勢力・中立地域
- リアルタイムの部隊移動
- CPU勢力の自動派遣
- 白いプレイヤー部隊をドラッグ／スワイプして領土へ派遣
- 派遣部隊の継続移動と到着後の巡回
- 部隊同士の接近戦と戦闘中エフェクト
- 領土選択による戦況確認
- 一時停止、1倍・2倍・4倍速
- マップの拡大・縮小・初期化
- ローカルシミュレーション用の設定ダイアログ

画像・音声の外部素材は使用していません。キャラクターやUIはコードで描画しているため、参考画像の素材をそのまま再配布しない構成です。

## ローカル確認

ビルドツール不要の静的サイトです。簡易サーバーを起動して `index.html` を開いてください。

```powershell
python -m http.server 8788
```

その後、ブラウザで `http://localhost:8788/` を開きます。

## Cloudflare Pages

- Framework preset: `None`
- Build command: 空欄
- Build output directory: `/`

GitリポジトリをPagesに接続する場合は、このディレクトリをそのまま静的サイトとしてデプロイできます。
